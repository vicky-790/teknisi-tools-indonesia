Privacy Policy

Saat ini kalkulator dasar dapat digunakan tanpa akun. Website menggunakan localStorage pada perangkat untuk menyimpan riwayat kalkulasi lokal dan service worker untuk fungsi PWA/offline. Data riwayat kalkulasi lokal tetap di browser pengguna dan dapat dihapus melalui fitur reset atau data situs.

Analytics

Cloudflare Web Analytics dapat digunakan untuk statistik trafik agregat dan performa situs. Mulai V1.7, Teknisi Tools Indonesia juga memiliki custom usage analytics untuk menghitung event penggunaan seperti membuka kalkulator, menekan Calculate, menyalin hasil, membuka artikel, klik Tools/Knowledge, CTA, dan instalasi PWA. Custom analytics hanya menyimpan jenis event, path halaman, label singkat halaman, waktu, serta session ID acak sementara. Nilai input kalkulator dan hasil perhitungan tidak dikirim ke database custom analytics. Sistem custom analytics tidak meminta atau menyimpan nama, email, nomor telepon, atau data akun pengguna.
