Saat ini kalkulator dasar dapat digunakan tanpa akun. Website menggunakan localStorage pada perangkat untuk menyimpan riwayat kalkulasi lokal dan service worker untuk fungsi PWA/offline. Data riwayat tersebut tetap di browser pengguna dan dapat dihapus melalui fitur reset atau data situs. Saat analytics, iklan, akun, atau layanan pihak ketiga diaktifkan, kebijakan ini akan diperbarui sebelum penggunaannya.

Analytics

Versi V1.5 menyiapkan integrasi analytics opsional. Jika Cloudflare Web Analytics atau Google Analytics diaktifkan di kemudian hari, platform dapat mengumpulkan data penggunaan agregat seperti halaman yang dibuka, perangkat/browser, sumber kunjungan dan informasi teknis serupa untuk memahami performa situs. ID analytics pada paket V1.5 dikosongkan secara default sehingga loader analytics tidak aktif sampai pemilik situs mengkonfigurasinya.
