GENERIC DTC LOOKUP

Mulai dari kode, lalu verifikasi wiring dan kondisi nyata.

Database bawaan hanya referensi generic powertrain code yang umum. Kode motor tertentu dapat berbeda menurut merek, model, tahun dan ECU.

Kalau kode tidak ada di database generic, tetap lanjutkan memakai service manual model kendaraan.
Masukkan kode DTC untuk melihat reference card dan urutan pengecekan awal.
MIL BLINK HELPER

Bantu hitung pola kedipan tanpa mengasumsikan arti kodenya.

Format blink berbeda antar model. Pilih konvensi hanya bila manual kendaraan memang menggunakannya.

Masukkan jumlah blink sesuai observasi aktual.
GUIDED SENSOR / ACTUATOR TEST

Bandingkan nilai ukur dengan spesifikasi manual Anda.

Kami sengaja tidak mengunci angka “normal” universal. Masukkan min/max dari service manual lalu bandingkan nilai pengukuran.

Pilih komponen dan masukkan nilai dari pengukuran + service manual.
SYMPTOM + DTC CORRELATION

Gabungkan kode dengan gejala sebelum mengganti komponen.

Masukkan gejala + kode/observasi untuk membangun urutan diagnosis.
IMPORTANT LIMITS

Jangan ganti sensor hanya karena ada DTC.

DTC sering berarti ECU melihat sinyal/circuit abnormal, bukan otomatis komponen rusak. Selalu cek supply, ground, konektor, wiring, kondisi mekanis terkait, lalu bandingkan nilai dengan service manual model yang benar.
